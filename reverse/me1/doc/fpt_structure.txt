FPT Structure Analysis
=========================

The firmware uses a standard Intel Flash Partition Table ($FPT) starting at 0x10.
The table contains entries for different firmware regions.

Known Partitions from Hex Dump:
-------------------------------
- 0x30: FOVD (Field Override Data)
- 0x50: EFFS (Embedded Flash File System?)
- 0x70: NVUP
- 0x90: NVKR (NVRAM Keys?)
- 0xB0: NVAL
- 0xD0: NVTP
- 0xF0: CODE -> Points to 0x72000, size 0x70000

This structure confirms the binary is a raw Intel ME firmware image.
