RIZIN ARC DISASSEMBLER PATCH
Intel ME1 Firmware Analysis - Missing Opcode Support
================================================================================

DATE: 2025-02-15
REPOSITORY: code/rizin (git submodule)
TARGET FILE: librz/arch/isa_gnu/arc/arcompact-dis.c
ISSUE: Missing handlers for ARCompact 16-bit shift opcodes 8, 10, 11

================================================================================
PROBLEM STATEMENT
================================================================================

Rizin ARC disassembler lacks support for three 16-bit ARCompact opcodes used
extensively in Intel ME1 firmware modules:

- OPCODE 8  (0x08): ASL_S - Arithmetic Shift Left (register-register)
- OPCODE 10 (0x0A): ASR_S - Arithmetic Shift Right (register-register)
- OPCODE 11 (0x0B): LSR_S - Logical Shift Right (register-register)

Total unknown instructions across 18 ME1 modules: 271
- ASL_S: 37 occurrences
- ASR_S: 147 occurrences
- LSR_S: 0 occurrences (register-register form)

Most common patterns:
- 0x8e53 (87x): ASR_S r14, r7, r0
- 0x2040 (24x): ASL_S r0, r0, r2
- 0x2050 (20x): ASR_S r0, r0, r2
- 0x6050 (20x): ASR_S r0, r0, r6

================================================================================
INSTRUCTION ENCODING REFERENCE
================================================================================

16-bit ARCompact format:

Bits 15-11: Major Opcode (5 bits)
Bits 10-8:  B field - Source register 1 (3 bits, maps to r0-r7)
Bits 7-5:   C field - Source register 2 (3 bits, maps to r0-r7)
Bits 4-0:   A field - Destination register (5 bits, maps to r0-r31)

Example: 0x8e53 (ASR_S r14, r7, r0)

Binary: 0101 0011 1000 1110
        ^^^^ ^^^^ ^^^^ ^^^^
        5    3    8    E

Breakdown:
- Bits 15-11: 01010 (10 decimal) = ASR_S opcode
- Bits 10-8:  011 (3 decimal) = r7 (but shifted, actual r7)
- Bits 7-5:   100 (4 decimal) = r0 (but shifted, actual r0)
- Bits 4-0:   01110 (14 decimal) = r14

Operation: r14 = r7 >> r0 (arithmetic shift right)
