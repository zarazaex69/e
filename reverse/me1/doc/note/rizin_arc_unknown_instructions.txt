================================================================================
ROOT CAUSE ANALYSIS
================================================================================

The Rizin ARC disassembler plugin lacks handlers for the following 16-bit
ARCompact major opcodes:

OPCODE 8  (0x08) - ASL_S (Arithmetic Shift Left, register-register)
OPCODE 10 (0x0A) - ASR_S (Arithmetic Shift Right, register-register)  
OPCODE 11 (0x0B) - LSR_S (Logical Shift Right, register-register)

These opcodes are defined in the ARC Architecture Programmer's Reference but
are not implemented in the switch-case statement of dsmOneArcInst() function.

FILE: librz/arch/isa_gnu/arc/arcompact-dis.c
FUNCTION: dsmOneArcInst()
LINE: ~752 (switch statement start)

================================================================================
DECODING CLASS REFERENCE
================================================================================

The Rizin ARC disassembler uses decodingClass variable to determine how to
interpret and display instruction operands. For shift instructions:

decodingClass = 16: Used for 3-operand instructions with format:
INSTRUCTION dest, src1, src2

Recommended decodingClass for opcodes 8, 10, 11: 16

Alternative classes to consider:
decodingClass = 14: Single operand instructions
decodingClass = 21: Immediate operand instructions
