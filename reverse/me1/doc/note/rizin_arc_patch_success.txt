CURRENT ANALYSIS WORKFLOW
==

STANDARD WORKFLOW (NO WORKAROUNDS NEEDED):

1. Open module in Rizin:
```
rizin -a arc -b 16 module.bin
```

2. Run automatic analysis:
```
aaa
```

3. List all functions:
```
afl
```

4. Disassemble specific function:
```
pdf @ function_address
```

5. Analyze cross-references:
```
axt @ address
axf @ address
```

EXAMPLE SESSION:
