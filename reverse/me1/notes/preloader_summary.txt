Analysis Summary: PRELOADER.bin

Meta Information
- Status: COMPLETED
- Architecture: ARC (16-bit instructions, 32-bit data/addressing)
- Load Address: 0x01000000 (Mapped Flash/ROM)
- Entry Point: 0x01012210 (Virtual) -> 0x00000000 (Physical offset in module)
- Role: Stage 1 Bootloader / Unpacker

Execution Flow Reconstruction

1. CRT0 & Setup
- Stack Pointer (SP): Sets sp to 0x01012210 (Top of module address).
- Global Pointer (GP): Sets gp to 0x010010fc (Points to Global Data Table at end of file).

2. Hardware Initialization (The "Blocking" Phase)
- Location: Function at offset 0x0bb0.
- Target: SRAM Controller / Memory Banks.
- Mechanism:
  - Polling loop using AUX registers 0x2C00 - 0x2C0F.
  - Reads pairs of registers (e.g., 0x2C00 & 0x2C01).
  - Waits until a condition (likely PLL lock or Bank Ready) is met.
  - CRITICAL: If emulating, these addresses MUST return values indicating "Ready", otherwise the code hangs forever.

3. Decompression (The "Missing Link")
- Location: Function at offset 0x0c78 (Main Loader) -> 0x0654 (Decompressor).
- Algorithm: Custom LZ/Huffman implementation.
- Source: Compressed data from Flash.
- Destination: SRAM (likely starting at 0x00100000).
- Artifact: Upon success, writes magic bytes $MEM (0x4D454D24) to the start of initialized memory.

4. Handoff (Jump to Next Stage)
- Mechanism: Indirect Jump (jl [r1]).
- Target Address Source: Read from Global Data Table (*0x1001100).
- Target Address: 0x00100000 (Start of SRAM).
- Next Module: BRINGUP.bin.

Key Findings for Next Stages
1. Environment: When BRINGUP starts, the SRAM is already initialized and writable.
2. Context: The processor is in a specific state with some AUX registers configured.
3. Memory Map:
   - 0x01000000: Flash / ROM (Read Only)
   - 0x00100000: SRAM (Read/Write, Executable)
   - 0x00002Cxx: Memory Controller IO
