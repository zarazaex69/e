# Boot Modules

Modules responsible for firmware initialization and loading.

## Modules

- [BRINGUP](BRINGUP.md) - Initial boot and hardware initialization
- [PRELOADER](PRELOADER.md) - Loads kernel and other modules
- [BUCLS_OVL](BUCLS_OVL.md) - Boot capability licensing
- [BUPMSEQ_OVL](BUPMSEQ_OVL.md) - Boot power management sequence
