# Kernel Modules

Core operating system modules providing privileged and non-privileged execution environments.

## Modules

- [KernelPriv](KernelPriv.md) - Privileged kernel operations (LZMA compressed, 240KB)
- [KernelNonPriv](KernelNonPriv.md) - Non-privileged kernel operations (LZMA compressed, 250KB)

Both modules are LZMA compressed and loaded by PRELOADER during boot sequence.
