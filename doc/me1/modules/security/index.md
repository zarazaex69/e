# Security Modules

Cryptographic and security functionality modules.

## Modules

- [TPM](TPM.md) - Trusted Platform Module implementation (265KB compressed)
- [PKTPM](PKTPM.md) - TPM packet processing
- [PKTPMINIT_OVL](PKTPMINIT_OVL.md) - TPM initialization overlay
- [TDT](TDT.md) - Theft Deterrent Technology (Anti-Theft)

TPM module is the largest compressed module in ME1 firmware.
