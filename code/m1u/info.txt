m1u - Intel ME Firmware Module Extractor
=

Utility for extracting and decompressing modules from Intel Management Engine firmware.

FEATURES
--------
- FPT (Flash Partition Table) parsing
- CODE partition and $MAN manifest detection
- Module extraction by name
- LZMA decompression (Intel ME custom format)
- Uncompressed module support

USAGE
-----
./m1u <firmware.bin> [module_name]

Examples:
  ./m1u me1x200.bin                - Extract ALL modules automatically
  ./m1u me1x200.bin KernelPriv     - Extract specific module
  ./m1u me1x200.bin BRINGUP        - Extract specific module

OUTPUT
------
Extracted modules are saved to out/ directory
Format: out/<module_name>.bin

BUILD
-----
make

Requirements:
- zig cc
- liblzma (xz-utils)

TECHNICAL DETAILS
-----------------
Intel ME uses a custom LZMA format:
- 1 byte: properties (lc, lp, pb)
- 4 bytes: dictionary size
- Compressed data (WITHOUT 8-byte uncompressed_size field)

The program automatically converts to standard LZMA Alone format
by adding the correct uncompressed_size from $MOD entry.

$MOD ENTRY STRUCTURE
--------------------
Offset  Size    Field
------  ----    -----
0x00    4       Signature ($MOD)
0x04    4       Module ID
0x08    4       Module Type
0x0C    4       Flags1
0x10    4       Flags2
0x14    4       Reserved
0x18    4       Compressed Size
0x1C    4       Uncompressed Size
0x20    4       Load Address
0x24    4       Entry Point
0x28    8       Hash
0x30    16      Module Name
0x40    8       Padding

BATCH EXTRACTION
----------------
Running m1u without module name extracts ALL 18 modules automatically.
Progress is displayed for each module during extraction.
All modules are saved to out/ directory.

LIMITATIONS
-----------
- Only Intel ME 1.x/4.x/5.x format supported
- Some modules may be encrypted
- LZMA decompression may fail for newer ME versions
